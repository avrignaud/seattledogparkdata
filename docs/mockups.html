Internal · Design exploration · April 2026

Modernizing the site's type and chrome.

Two mockup directions for moving the site to a modern sans-serif feel — inspired by codex (OpenAI) and dropbox.com. Both preserve the existing color system (warm off-white, signal orange, navy, sage) and keep IBM Plex Mono for data kickers. The change is mostly typographic: retire Fraunces serif display, move to a modern grotesque for both headlines and body.

Option A

Clean Grotesque

Inter everywhere. Near-monochrome. One accent color, used surgically. Sharpest, most neutral direction — closest to codex/OpenAI.

Option B

Warm Modern

Space Grotesk display + Inter body. Rounded color-block cards. Keeps paper warmth; more personality; closer to Dropbox.

The pivot, in one line

Replace Fraunces serif (display) with a modern grotesque used for both display and body. Keep IBM Plex Mono for metadata. Tighten letter-spacing on display sizes (-0.03 to -0.045em), reduce font weight on headlines (600, not 800), and let whitespace — rather than borders and rules — carry the structure.

What changes vs. the current site

  • Headline font: Fraunces 800 italic → Inter 600 (Mockup A) or Space Grotesk 500 (Mockup B). Both handle large display sizes with tight tracking.
  • Body font: IBM Plex Sans 300 → Inter 400. Inter has better screen-rendering at small sizes, wider weight range, and a more current feel.
  • Background: #F6F2E9 (warm cream) stays in B; shifts to a cooler #FAFAF7 in A. Both avoid pure white.
  • Chrome: The current "broadsheet" masthead (6px top border, mono dateline) softens in A (hairline rule only) and transforms in B (pill-shaped dark top bar).
  • Cards: Sharp rectangles with L-bracket corner flags → rounded (14px in A, 20px in B), with hover lift instead of corner ornament.
  • Buttons: The site didn't really have any; both mockups add a primary/ghost button pattern for the hero.
  • Color: A uses color surgically (orange only for the hero number and one or two accents). B uses color-blocked tiles for the four stats — each stat in its own pastel tile (orange / navy / sage / gold), taking the existing palette and using it more fully.

What doesn't change

  • Content, IA, and URLs. These are visual mockups of the landing page only — no copy changes.
  • Still a static HTML site from /docs. No build step. Google Fonts from CDN.
  • IBM Plex Mono still does the kicker/label/metadata work — it's the one font that already works and shouldn't be touched.
  • Chart.js + Leaflet remain the chart/map layer. Both mockups are the landing page only; report pages (Part I/II/III) would follow the same typographic system but aren't mocked yet.

Recommendation

Start with Option A. It's the smallest change from today's structure, reads as "data reference" rather than "SaaS landing", and matches the facts-first pivot in CLAUDE.md. Borrow one idea from B: the color-blocked stat tiles (they're a genuine upgrade over the current newspaper-style stat row, especially on mobile where the current row collapses awkwardly).

The one caveat I'd flag on B: the dark hero card and pill nav read a bit marketing-y, which fights the civic-data positioning. If you like B's warmth but not its SaaS feel, the fix is to keep the colored stat tiles and rounded cards but revert the hero to a flat paper background.

Open questions

  • Keep the warm cream background, or move to a cooler off-white? (B keeps it; A moves cooler.)
  • Is there appetite for a slight amount of personality in the display face (Space Grotesk, with its distinctive italic) — or do you want the most neutral grotesque possible (Inter)?
  • Does the opinion page need its own visual treatment to read clearly as "this is the opinion part"? Mockup B tries a gold-background callout strip; A uses only a navy left-rule.
  • Should the report pages (Part I/II/III) get mocked next, or is landing-page direction enough to commit first?
