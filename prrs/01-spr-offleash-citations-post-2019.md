## Subject

Seeking off-leash dog citation data, October 16, 2019 to present

## Body

Hello,

I am requesting an extension of public records request C049204 (originally filed 2019-08-29 and produced 2019-10-15 by SPR). That request returned five Excel workbooks containing all off-leash dog citations issued by Seattle Animal Control between January 1, 2014 and October 15, 2019, with columns for violation number, offense level, item code, fee, issue date/time, address, city, state, zip code, and cross street.

I would like the same record set for the time period **October 16, 2019 to the present date**, in the same format if possible. Specifically, citations issued under Seattle Municipal Code 18.12.080(A) ("Parks Code — Dog Loose in Park"), all offense levels.

This data will be used for civic data analysis at seattledogparkdata.com, a public-interest project analyzing Seattle's off-leash area system. The earlier response from C049204 is already published there in full.

If this request would be better directed to Seattle Animal Control, the Seattle Police Department, or another department, please let me know the appropriate routing.

Thank you,

Andre Vrignaud
Queen Anne, Seattle, WA
seattledogparkdata@ozymandi.as

## Analysis purpose

Once received, this data will:
- Extend the [enforcement hotspot analysis](../docs/enforcement.html) through present
- Resolve whether the 2015–2018 upward trend continued, plateaued, or reversed after COVID and the 2020 budget compression
- Support year-over-year comparison against the published 4,803-citation baseline
