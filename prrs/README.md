## On the tone

Seattle's PRR process works best with narrow, specific requests that name the record type and timeframe. The drafts in this directory follow that style: short body, specific date range, specific record type, stated purpose, and a line inviting SPR/SPU to redirect the request if another department is the better owner. Keep new drafts in the same register.
