Context for any AI coding agent (Codex, Claude Code, etc.) working on this

## What this is

A civic-data project about Seattle's off-leash dog area (OLA) system. The
site is a public data reference with a clearly-demarcated opinion page. It
lives at **seattledogparkdata.com** (Cloudflare Pages, served from `docs/`).
Repo: **github.com/avrignaud/seattledogparkdata**.

## Framing (not editorial — facts first)

The site is organized as:

1. **A public data reference.** Numbers, charts, maps, sources, methodology.
   Every chart block carries a `chart-source` footnote linking primary data.
2. **One clearly-labeled opinion page** (`docs/opinion.html`) with principles,
   counter-arguments, and a policy recommendation. Visually distinct; never
   blend into the data pages.

If you're adding new content: keep factual claims on the report pages and
link back to primary sources. Opinion goes on the opinion page. Don't mix
them.

## Working style (Andre's preferences)

- **Direct, no preamble.** Get to the point. Don't recap what was just said.
- **Informal but substantive.** Not chatty, not stiff.
- **Honest pushback valued.** If a proposed change is wrong or a data point
  is weak, say so. Don't agree reflexively.
- **No trailing follow-up questions.** End responses when they're done.
- **Praise is fine when warranted**, but don't flatter.
- **Every factual claim links to its primary source.** No bare numbers.

- **No build step for the site.** Static HTML + vanilla CSS + Chart.js /

  (node + puppeteer + pdf-lib), and it runs in CI, not on the site itself.
- **Fonts:** Fraunces (serif display), IBM Plex Sans (body), IBM Plex Mono
  (metadata). Google Fonts.
- **Color palette** (CSS vars, top of each HTML file):
  - `--bg` #F6F2E9 (warm off-white paper)
  - `--ink` #121820 (near-black)
  - `--accent` #C04A1E (signal orange — Seattle data)
  - `--accent-2` #4C6B54 (sage — peer cities / positive / walksheds)
  - `--accent-3` #2C4A6E (navy — editorial band / opinion page)
  - `--accent-4` #A68A2E (amber — methodology callouts / OLA-host hotspots)
  - `--danger` #8B2518 (deep red — Kinnear)
- **Charts:** Chart.js 4.4.0 + chartjs-plugin-datalabels 2.2.0. Use

  per chart unless necessary.
- **Maps:** Leaflet 1.9.4 + leaflet.heat 0.2.0. CARTO `light_all` tiles with
  `subdomains: 'abcd'`. For walkshed polygons, load
  `data/walkshed/ola_isochrones.geojson` (network isochrones, not straight-
  line circles).
- **CSP** is enforced via `docs/_headers`. `style-src` must include
  `https://unpkg.com` (for leaflet.css) and `https://fonts.googleapis.com`.
  `img-src` must include the CARTO tile host.
- **CSV format:** Plain CSV, no comment headers. Every reference CSV carries
  a `provenance` column (sourced / calculated / interpolated / estimated /
  missing). Don't add/reorder columns without updating whatever reads them.
- **Writing voice:** Restrained. Fraunces italic for emphasis. Short
  sentences preferred over long ones. No em-dashes used as commas when a
  comma would do. See recent commits by Andre for tone; the
  `andre-voice` skill encodes the house voice.

## Data methodology — things that will bite you (updated April 2026)

### 1. The walkshed number
Was a ~33% straight-line estimate. **Now 11.7% network walk (alpha-shape)** via
`scripts/compute_walkshed.py` (osmnx against Seattle's full OSM walk
network, projected to UTM 10N) + `scripts/population_coverage.py` (2020
Census block-group overlay via pygris). Output in
`data/walkshed/population_coverage.csv`. Alpha-shape (α=0.003) with 0.3 km²
area floor + convex-hull fallback for edge-of-network OLAs like Westcrest.

### 2. Peer-city OLA counts use different definitions
Portland's 30+ DOLAs include unfenced voice-control. Seattle counts
fenced-only. SF mixes. Vancouver includes time-restricted shared-use.
**DC has exactly 16 fenced DPAs** (earlier drafts said 20 — reconciled
April 2026 against dpr.dc.gov). Austin's ~80 fenced acres is the
apples-to-apples figure, not the 682-acre inflated total.

### 3. The OLA budget is not really the OLA budget
SPR's "Maintaining Parks & Facilities" BSL (BC-PR-50000) funds BOTH OLAs
AND P-Patch community gardens. Post-2018 OLA-only splits are not
publicly disclosed; PRR #3 is out to request them.

### 4. Dog population — three-tier triangulation
No longer a single 150K floor. Site cites three independent estimates:
- **Licensed floor:** ~26,700 active dog licenses (Seattle Open Data
  `jguv-t9rb`).
- **AVMA-derived demographic estimate:** 364,627 Seattle households ×
  42.6% × 1.6 dogs/HH ≈ 248,500 (AVMA 2025 Sourcebook + ACS 2023).
- **SPR 2023 Expansion Study:** 187K–400K.
The working floor for per-dog math stays at 150K (below all three by
design).

### 5. OLA coordinates
**Now authoritative.** Pulled April 2026 from SPR's Dog Off-Leash Areas
ArcGIS FeatureServer. Replaces the earlier address-derived
approximations. Several points moved 0.3–1.5 km.

### 6. Enforcement data
`data/enforcement-citations.csv` — 7,532 rows from PRRs C049204 + C263949
(2014-01-01 to 2026-04-17; 3,774 retained from C049204, 3,758 from C263949).
DLP-only subset is 7,015 rows (`dlp_only=True`). Each row has `location_type`:
- `park_named` (6,719 rows, 89.2%) — canonical park name
- `street_address` (695 rows, 9.2%) — unresolved street address, flagged
  but not geocoded
- `unknown` (118 rows, 1.6%) — no location in source

Revenue analysis uses the actual `fee` column sum ($351,099 cumulative over
the full window), not a theoretical upper bound. FAS ACO II cost disclosure
($152,399/yr) is from the signed 2021 MOA at `data/moas/SPR-FAS-ACO2-MOA-2021-…pdf`.

### 7. Access × citation overlap
**71.9% of geocoded park-named citations** (73.4% including Census-geocoded
street addresses) fall outside any OLA's 0.5-mi walkshed. Computed as
point-in-polygon intersection of `data/park-coordinates.csv` against
`data/walkshed/ola_isochrones.geojson`. OLA host parks use authoritative
SPR ArcGIS OLA coordinates (reconciled April 2026) so the lookup aligns
with the walkshed seed. Reproducible via
`scripts/citation_walkshed_analysis.py`; output in
`data/walkshed/citation-rate-by-walkshed-status.csv`.

## PDF pipeline (the tricky piece)

`docs/print.html` is a dedicated print-first template. It carries the
condensed version of the six pages in reading order, with Chart.js
charts + Leaflet maps rendering as canvases + SVG. `scripts/build-pdf.mjs`
uses puppeteer with `emulateMediaType('screen')` (NOT 'print' — that
freezes Chart.js and leaves canvases blank), starts a tiny static
server over `docs/`, renders print.html at Letter size, and writes
`docs/seattle-dog-parks-report.pdf`.

CI regenerates the PDF on every push to main that touches `docs/`,
`scripts/build-pdf.mjs`, or `package.json`. Retries 5× on push rejection
to handle races with developer pushes.

**Gotchas:**
- Media emulation: use `screen`, not `print`. Print media freezes
  Chart.js canvas rendering.
- Wait: `waitForFunction('window.__walkshedReady === true')` with a 30s
  timeout plus a 6s fallback setTimeout. Leaflet tile loads + Chart.js
  animation + font load all need settling time.
- Geojson mirror: print.html fetches `data/walkshed/ola_isochrones.geojson`
  — that path resolves to `docs/data/walkshed/...` because the puppeteer
  server roots at `docs/`. The geojson lives both at `data/walkshed/` (for
  repo reproducibility) and mirrored to `docs/data/walkshed/` (for
  Cloudflare deploy).
- Leaflet z-order: in the walkshed map, add the geojson polygons FIRST,
  then the OLA circle markers, so the markers sit on top.
- Chart.js datalabels + null data: always guard
  `display: ctx => ctx && ctx.parsed && ctx.parsed.y != null`.
- Tables: `thead { display: table-header-group }` + `tr { break-inside:
  avoid }` to stop row-level splits across pages.

## Running locally

```
# Serve the site locally
cd docs/
python3 -m http.server 8000
# → http://localhost:8000/

# Rebuild the PDF locally
npm install        # first time only
npm run build:pdf  # writes docs/seattle-dog-parks-report.pdf

# Rerun the walkshed analysis (requires Python env with osmnx + pygris)
python3 -m venv .venv
.venv/bin/pip install osmnx geopandas shapely pandas pygris requests scipy
.venv/bin/python scripts/compute_walkshed.py
.venv/bin/python scripts/population_coverage.py
```
